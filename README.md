# Hayanmi Detailing — сайт + Telegram-бот

Что внутри:

- **Сайт** с формой записи. Работает как обычный сайт и как Mini App внутри бота.
- **Telegram-бот**:
  - `/start` — кнопка «Записаться» (открывает сайт прямо в Telegram);
    админам дополнительно кнопка «Заявки»;
  - `/admin` — открыть панель заявок (только админам);
  - `/id` — показывает ваш ID и ID чата (нужно для настройки).
- **Новые заявки** приходят в ваш чат/группу с кнопками статуса:
  «Перезвонили», «Записан», «Выполнено», «Отказ».
- **Панель заявок** — Mini App внутри бота: список заявок, звонок в одно
  нажатие, смена статуса. Пароль не нужен: бот узнаёт админов по их Telegram ID.
- Заявки хранятся в PostgreSQL. Картинки скачиваются автоматически при
  `npm install` (скрипт `scripts/fetch-assets.js`).

## Запуск на Railway

1. Создайте бота в **@BotFather** (`/newbot`) и скопируйте токен.
2. Загрузите эту папку в новый репозиторий на GitHub.
3. Railway: **New Project → Deploy from GitHub repo** → выберите репозиторий.
4. В проекте: **+ New → Database → PostgreSQL**.
5. В сервисе сайта: **Settings → Networking → Generate Domain**.
6. В сервисе сайта → **Variables** добавьте:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `TELEGRAM_BOT_TOKEN` = токен из шага 1
   - `ADMIN_IDS` = ID админов через запятую, например `111111111,222222222`
   - `TELEGRAM_CHAT_ID` = куда слать заявки (ваш ID или ID группы, у группы он с минусом)

   Адрес сайта для бота берётся автоматически из домена Railway.
   Если подключите свой домен, добавьте `PUBLIC_URL` = `https://ваш-домен`.

### Как узнать ID

После первого запуска напишите своему боту `/id`: он пришлёт ваш ID.
Для группы: добавьте бота в группу и напишите там `/id` — он пришлёт ID группы.
Впишите эти числа в переменные и Railway перезапустит сервис.

## Что поменять

Телефон, адрес, часы и Instagram указаны в `public/index.html`
(ищите `+992 00 000 00 00` и `адрес появится скоро`).

## Важно

Бот работает через long polling внутри этого же сервиса, поэтому держите
**одну** копию сервиса (Replicas = 1) и не подключайте к этому боту вебхук
из других мест.

## Локально

```
npm install
npm start
```
Сайт откроется на http://localhost:3000.
